# AgentForge

An AI Engineering Platform for building, evaluating and orchestrating local AI systems using open-source LLMs.

## Features

- Local LLM Chat
- Model Manager
- Prompt Playground
- RAG Studio
- Agent Builder
- Memory Inspector
- Evaluation Dashboard

## Tech Stack

Frontend
- React
- TypeScript
- TailwindCSS

Backend
- FastAPI
- LangGraph

AI
- Ollama
- Qwen

Database
- SQLite
- Qdrant
