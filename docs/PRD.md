# Product Requirements Document (PRD)

## Project Name

AgentForge

---

## Vision

AgentForge is a local AI Engineering Platform that enables developers, students, and researchers to build, test, evaluate, and orchestrate AI workflows using open-source large language models.

---

## Problem Statement

Current AI development requires using multiple disconnected tools such as Ollama, LangGraph, Qdrant, LM Studio, NotebookLM, and custom scripts.

There is no unified platform where developers can experiment with every stage of AI engineering from one interface.

AgentForge solves this by providing a single platform for model management, prompt experimentation, retrieval-augmented generation (RAG), workflow orchestration, evaluation, and memory management.

---

## Target Users

- AI Engineers
- Machine Learning Engineers
- Students
- Researchers
- Software Developers

---

## Goals

- Learn AI Engineering
- Experiment with local LLMs
- Build AI agents
- Build RAG pipelines
- Compare multiple models
- Evaluate model performance
- Visualize AI workflows

---

## Non Goals

- Voice Assistant
- Image Generation
- Video Generation
- Cloud Deployment
- Mobile Application

---

## Core Modules

### Dashboard

Displays system metrics and project overview.

### Chat Playground

Local chat interface with multiple conversations.

### Model Manager

Manage installed Ollama models.

### Prompt Playground

Compare prompts across multiple models.

### RAG Studio

Upload documents and chat with them.

### Memory Inspector

View and manage long-term AI memory.

### Tool Registry

Manage available AI tools.

### Agent Builder

Create visual AI workflows.

### Evaluation Dashboard

Benchmark models and prompts.

---

## Success Criteria

- Fully local execution
- Modular architecture
- Production-ready codebase
- Extensible plugin system
- Comprehensive documentation
